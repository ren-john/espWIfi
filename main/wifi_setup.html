Connect to Wi-Fi

Use a 2.4 GHz network. For a phone hotspot, copy its name and password from your phone's hotspot settings.

Leave the password empty only for an open network. A saved password is never shown here.

The ESP restarts after saving. If this phone will provide the hotspot, enable it after saving. Some phones turn off Wi-Fi when their hotspot starts.

If connection fails, the ESP hotspot returns within about 30 seconds. It continues trying to connect.
